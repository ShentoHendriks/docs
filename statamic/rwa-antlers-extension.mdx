The RWA Statamic Antlers Extension turns `.antlers.html` files into a project-aware VS Code editing environment for Statamic sites.

It understands Antlers syntax, Statamic project folders, blueprints, fieldsets, partials, collections, taxonomies, globals, assets, Bard, Replicator sets, Grid fields, Entries relationships, Tailwind classes, and common Rainy Weather Agency template workflows.

## Best used for

Use the extension when building Statamic sites with:

- Antlers templates in `resources/views/**/*.antlers.html`
- Collection-driven pages and taxonomy routes
- Blueprint-heavy content models
- Reusable partials
- Bard, Grid, and Replicator page builders
- Entries relationship fields
- Asset-heavy layouts
- Tailwind or utility-based styling

It is especially useful on larger projects where exact field handles, set handles, partial paths, and content contexts become too much to keep in your head.

## Daily workflow

A typical workflow looks like this:

```html
<main>
  <h1>{{ title }}</h1>

  {{ page_builder }}
    {{ partial src="sets.pages.{type}" }}
  {{ /page_builder }}
</main>
```

While you type, the extension can suggest:

- `title` from the current blueprint
- `page_builder` as a Replicator field
- `type` inside Bard or Replicator loops
- `sets.pages.hero_section` from real partial files
- child fields inside the selected Replicator set partial
- asset variables such as `url`, `alt`, `width`, and `height`
- collection, taxonomy, global, nav, and partial handles from project files

## Extension settings

The extension contributes these defaults for Antlers files:

```json
{
  "[antlers]": {
    "editor.defaultFormatter": "local.rwa-antlers-support",
    "editor.wordBasedSuggestions": "off",
    "editor.snippetSuggestions": "bottom",
    "editor.quickSuggestions": {
      "strings": "on"
    }
  },
  "emmet.includeLanguages": {
    "antlers": "html"
  },
  "emmet.showSuggestionsAsSnippets": true,
  "tailwindCSS.includeLanguages": {
    "antlers": "html"
  }
}
```

The optional language server can be disabled when you only want highlighting, formatting, tag pairing, and extension-side IntelliSense:

```json
{
  "antlers.languageServer.enabled": false
}
```

## Commands and shortcuts

| Feature | Command or shortcut |
| --- | --- |
| Normalize tag spacing | **Antlers: Normalize Tag Spacing** |
| Open suggestions on demand | `Ctrl+.` on Windows/Linux, `Command+.` on macOS in Antlers files |
| Insert selected suggestion example | `Ctrl+Enter` on Windows/Linux, `Command+Enter` on macOS while IntelliSense is open |
| Extract to partial | **Antlers: Extract to Partial** quick action |
| Create Replicator set | **Antlers: Create Replicator Set** quick action |
| Create field | **Antlers: Create Field** quick action |
| Set page blueprint | **Antlers: Set Blueprint** quick action |
| Create folder in Extract to Partial picker | `Ctrl+N` on Windows/Linux, `Command+N` on macOS |
