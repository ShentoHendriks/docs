The extension includes built-in diagnostics for Antlers syntax, Statamic conventions, and common template mistakes.

Diagnostics are provided by the optional language server.

## Filename conventions

The extension follows Statamic view conventions.

It can warn or error when:

- Antlers views do not use `.antlers.html`
- View filenames are not lowercase
- View filenames are not hyphen-separated
- Partial files are missing the leading underscore
- Partial filenames use hyphens after the leading underscore

For example, a partial should use:

```text
_card.antlers.html
```

and be referenced without the underscore:

```html
{{ partial:card }}
```

A file named `_footer-baby.antlers.html` should be renamed to:

```text
_footer_baby.antlers.html
```

## Filename quick fixes

Filename diagnostics include quick fixes that rename the current view to the suggested convention.

The quick fix can suggest:

- Lowercase filenames
- Hyphen-separated normal view filenames
- Underscore-prefixed partial filenames
- Underscore-separated partial names after the leading `_`

## Tag-pair diagnostics

The extension validates Antlers tag pairs using Statamic syntax.

Opening tags must close with a slash:

```html
{{ collection from="projects" }}
  {{ title }}
{{ /collection }}
```

A repeated block tag where a closing tag is expected is reported with guidance to use the slash form.

```html
{{ collection }}
  {{ title }}
{{ collection }}
```

The extension suggests:

```html
{{ /collection }}
```

## Missing, unexpected, and mismatched tags

Diagnostics cover:

- Unclosed Antlers block tags
- Unexpected closing tags
- Mismatched closing tags
- Delimiter count mismatches
- Repeated opening tags that probably need `/`

For example:

```html
{{ if featured }}
  {{ title }}
```

is reported as an unclosed tag pair.

## Partial tag rules

Explicit paired partial blocks are accepted:

```html
{{ partial:eyebrow }}
  Send us a mail
{{ /partial:eyebrow }}
```

Standalone partial tags remain valid:

```html
{{ partial:eyebrow }}
```

Repeated partial shorthand with block content between the tags is treated as a missing closing slash.

```html
{{ partial:eyebrow }}
  Send us a mail
{{ partial:eyebrow }}
```

The extension suggests:

```html
{{ /partial:eyebrow }}
```

## Scalars and namespaced tags

Scalar namespaced tags inside HTML attributes do not require closing tags.

```html
<html lang="{{ site:short_locale }}">
```

Nested or repeated conditionals are allowed and are not treated as missing slashes.

```html
{{ if og_image }}
  {{ if title }}
    {{ title }}
  {{ /if }}
{{ /if }}
```

## Broken Antlers inside attributes

The extension detects when a quoted HTML attribute closes before the Antlers tag closes.

```html
<meta content="{{ meta_title ?? title ?? ">
```

In this case, diagnostics focus on the broken attribute instead of flooding the parent block with follow-on errors.

## Blueprint-backed block diagnostics

Workspace-indexed global sets and blueprint block fields are included in missing closing tag diagnostics.

This includes:

- Grid fields
- Replicator fields
- Entries fields
- Multi-value Select fields
- Multi-asset fields
- Global set handles

Bard fields are excluded from missing closing tag diagnostics because they are often rendered as scalar content.

## Spacing advice

The extension warns when Antlers braces are written without consistent inner spacing.

```html
{{title}}
```

Use:

```html
{{ title }}
```

You can also use **Antlers: Normalize Tag Spacing** to clean up tag spacing.

## Case advice

Style advice calls out names that begin with uppercase letters.

Statamic Antlers names are case-sensitive, and official examples generally use lowercase names with underscores.

Prefer:

```html
{{ featured_image }}
```

instead of:

```html
{{ FeaturedImage }}
```

## When diagnostics update

Diagnostics update as documents change and when indexed workspace data changes.

If the language server is disabled, language-server diagnostics are not shown, but formatting, highlighting, tag-pair helpers, and completion features can still run.
