title: "Container overview"
---

Rainy Weather Framework exports one base container utility with optional modifier classes:

```text
container-grid
container-grid vw
container-grid fullscreen
container-grid fullscreen vw
```

`container-grid` defines the layout context for your page. It is not only a width wrapper. It also sets the CSS variables used by column utilities like `w-col-*`, `ml-col-*`, `pl-col-*`, `pr-col-*`, `gap-col-*`, and `gap-x-col-*`.

Use `container-grid` at section or layout-wrapper level before using grid-based utilities inside it.

```html
<section class="container-grid">
  <div class="w-col-6">
    ...
  </div>
</section>
```

## Container modifiers

Add modifiers after `container-grid` when the section needs a different mode.

```html
<section class="container-grid vw">
  ...
</section>

<section class="container-grid fullscreen">
  ...
</section>
```

`vw` enables viewport-based scaling for the container and for descendant text-variable utilities.

`fullscreen` makes the container use fullscreen grid math while keeping generated padding, margin, and gutter rules. It is scoped to `container-grid` and does not enable text `vw` scaling by itself.

Use both modifiers when you need fullscreen layout and viewport-scaled descendant text:

```html
<section class="container-grid fullscreen vw">
  ...
</section>
```

## What Containers Control

The container sets the active grid environment:

- container width
- container side margin
- gutter size
- active column count
- calculated column width
- mobile/desktop column switching

The generated CSS includes variables such as:

`--container-columns-mobile`\
`--container-columns-desktop`\
`--container-switch`\
`--container-width`\
`--spacing-container-margin`\
`--spacing-container-gutter`\
`--container-column-width`

You usually do **not** use these variables directly. The exported utility classes use them for you.

For example, `w-col-6` calculates its width from the current container’s column width and gutter value. That means the same class can behave differently depending on the active container modifiers, while still following the same design system.

## Removed aliases

The generated CSS no longer exports these old container classes:

```text
container-grid-fluid
grid-fluid
container-grid-fullscreen
```

Use `container-grid vw` and `container-grid fullscreen` instead.
