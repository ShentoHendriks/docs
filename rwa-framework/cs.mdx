---
title: "VW text modifier"
---

`vw` is a modifier class for generated text-variable utilities.

Use `container-grid vw` when a normal contained section should keep the regular `container-grid` layout while enabling viewport-scaled descendant text variables.

```html
<section class="container-grid vw py-section-2xl">
  <h1 class="display-l">A viewport-scaled headline.</h1>
</section>
```

`container-grid vw` does **not** make the section fullscreen. It keeps the same max width, margin, gutter, and column logic as `container-grid`.

## Text scaling inside `container-grid vw`

When `vw` appears on a container or another ancestor, descendant text-variable utilities use their viewport-scaled font-size value:

```html
<section class="container-grid vw">
  <h1 class="display-l">Large-screen headline</h1>
</section>
```

This replaces the old separate `display-l-vw` style utilities.

Use `!vw` on a text variable to opt out locally:

```html
<section class="container-grid vw">
  <h1 class="display-l !vw">VW context, capped headline.</h1>
</section>
```

`!vw` only works on the same element as the text variable. It does not block `vw` for a whole subtree.

## Fullscreen with `vw`

Use `container-grid fullscreen vw` when a section needs fullscreen grid math and descendant text scaling:

```html
<section class="container-grid fullscreen vw">
  <h1 class="display-l">Fullscreen layout with fluid type.</h1>
</section>
```

## Removed aliases

The generated CSS no longer exports `container-grid-fluid`. Use `container-grid vw` for text scaling, or `container-grid fullscreen vw` when the layout should also be fullscreen.
