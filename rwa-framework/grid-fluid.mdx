---
title: "Removed: grid-fluid"
---

`grid-fluid` is no longer exported by the generated CSS.

Use `container-grid vw` when you want the normal contained grid and viewport-scaled descendant text:

```html
<section class="container-grid vw">
  <h1 class="display-l">Viewport-scaled section.</h1>
</section>
```

Use `container-grid fullscreen` for full viewport grid math while keeping generated padding, margin, and gutter rules:

```html
<section class="container-grid fullscreen">
  <h1 class="display-l">Fullscreen section.</h1>
</section>
```

Use both modifiers when the section needs fullscreen layout and descendant text scaling:

```html
<section class="container-grid fullscreen vw">
  <h1 class="display-l">Fullscreen layout with fluid type.</h1>
</section>
```

## Text scaling migration

Old separate text helpers are also removed.

```html
<h1 class="display-l vw">Viewport-scaled headline.</h1>
<h1 class="display-l !vw">Fixed headline inside a vw context.</h1>
```

Use `vw` to enable viewport-scaled text and `!vw` to opt out locally.
