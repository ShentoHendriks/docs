---
title: "Fluid grid"
---

`grid-fluid` is a full-width fluid grid container without side padding.

Use it when layout should use viewport-wide grid math, but you do not want the side padding from `container-grid-fluid`.

```html
<section class="grid-fluid">
  <h1 class="display-l">Large screen headline</h1>
</section>
```

It:

- fills full available width
- caps itself to configured `--container-width` below max viewport
- switches to `100vw` above max viewport
- does not add `--spacing-container-margin` as side padding
- uses same gutter, column count, and mobile switch logic as other containers
- lets text styles keep scaling after max viewport by default

Use `grid-fluid` for:

- full-width sections without container padding
- custom wrappers that manage their own spacing
- layouts where edge alignment is handled by child elements
- wide editorial or visual sections that still need column math

### Font Scaling Inside `grid-fluid`

Text styles inside `grid-fluid` keep scaling after the max viewport breakpoint, same as `container-grid-fluid`.

```html
<section class="grid-fluid">
  <h1 class="display-l">Grid fluid, viewport-scaled headline.</h1>
</section>
```

Use the matching `*-no-vw` helper when one text style should stay capped inside `grid-fluid`.

```html
<section class="grid-fluid">
  <h1 class="display-l-no-vw">Grid fluid, capped headline.</h1>
</section>
```
