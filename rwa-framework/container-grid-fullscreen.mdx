---
title: "Fullscreen container modifier"
---

`fullscreen` is a modifier for `container-grid`.

Use `container-grid fullscreen` when a section should use full viewport width for grid calculations while still keeping generated padding, margin, and gutter rules.

```html
<section class="container-grid fullscreen py-section-xl">
  <div class="pl-col-1 pr-col-1">
    <h2 class="heading-h2">Fullscreen layout area.</h2>
  </div>
</section>
```

It:

- fills full viewport width
- does not cap itself to configured container width
- keeps side padding from `--spacing-container-margin`
- calculates column width from `100vw`
- uses the same desktop/mobile column count logic
- switches to mobile columns below `--container-switch`

This is useful when a layout area is full bleed, but still needs consistent grid math.

Use `container-grid fullscreen` for:

- full-bleed sections
- app-like canvases
- media-heavy layouts
- horizontal compositions
- background sections where content aligns to grid
- sections that should ignore max container width

## Font scaling inside `container-grid fullscreen`

`fullscreen` changes layout width, but text styles keep normal capped typography by default.

```html
<section class="container-grid fullscreen">
  <h1 class="display-l">Fullscreen layout, controlled type.</h1>
</section>
```

Add `vw` when descendant text variables should use viewport-scaled font sizes:

```html
<section class="container-grid fullscreen vw">
  <h1 class="display-l">Fullscreen layout, fluid type.</h1>
</section>
```

Or add `vw` to a single text variable:

```html
<section class="container-grid fullscreen">
  <h1 class="display-l vw">Fullscreen layout, fluid type.</h1>
</section>
```

Use `!vw` on a text variable to force the fixed font-size value when it would otherwise inherit `vw`.

## Removed alias

The generated CSS no longer exports `container-grid-fullscreen`. Use `container-grid fullscreen` instead.
