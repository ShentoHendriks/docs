The RWA Antlers VS Code Extension is a complete VS Code toolkit for writing Statamic Antlers templates with IntelliSense, formatting, diagnostics, refactors, and project-aware suggestions.

It turns `.antlers.html` files into a smarter editing environment that understands common Statamic project structure, including blueprints, assets, partials, collections, globals, taxonomies, Bard, Replicator, Grid fields, Entries relationships, HTML, and Tailwind classes.

## Install the extension

Download the latest `.vsix` file from the [GitHub repository](https://github.com/ShentoHendriks/RWA-Statamic-plugin), then install it in VS Code.

In VS Code, run **Extensions: Install from VSIX…** and select the downloaded file.

## Example

When the current page blueprint has `title` and `featured_image` fields, the extension can help you build markup like this:

```html
<h1>{{ title }}</h1>

{{ featured_image }}
  <img src="{{ url }}" alt="{{ alt ?? title }}">
{{ /featured_image }}
```

The field names come from the current blueprint. Inside the asset block, `url`, `alt`, and `title` come from the selected asset context.
